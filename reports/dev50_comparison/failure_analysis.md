# 50 题两组实测：结果与失败原因

正式实验已完成：同一套 D01–D50，关闭重规划与最多重规划 2 次各运行 50 个任务。模型为 `deepseek-v4-pro`；数据库为已核验的同一 PostGIS 数据快照。原 D01–D20 保留题干和难度，新增 30 题；全部标准答案均由独立只读 SQL 重新计算并核验。

## 实测结果

| 指标 | 关闭重规划 | 开启重规划 |
| --- | ---: | ---: |
| 正确题数 | 48/50 | 46/50 |
| 最终正确率 | 96% | 92% |
| 首轮正确率 | 96% | 92% |
| 实际作答轮数 | 50 | 58 |
| 实际重规划次数 | 0 | 8 |
| 首轮失败后挽回题数 | 0 | 0 |
| 全轮次工具调用数 | 285 | 355 |
| LLM 调用数 | 480 | 555 |
| 服务端报告 token 总数 | 3,098,170 | 3,733,356 |
| 平均单题耗时 | 29.571 秒 | 30.086 秒 |
| 单题耗时中位数 | 23.086 秒 | 23.703 秒 |
| 单题耗时 P95 | 44.452 秒 | 81.834 秒 |

开启组的工具调用增加 24.56%，token 增加 20.50%。两组逐题耗时之和分别约 1478.55 秒和 1504.30 秒；题目并发数为 4，整批调度墙钟耗时约 874.55 秒。这些时间不能互相替代。

原 20 题的正确数为关闭组 19/20、开启组 18/20；新增 30 题为关闭组 29/30、开启组 28/30。

## 失败题逐项核查

| 题号 | 关闭组 | 开启组 | 主要证据 |
| --- | --- | --- | --- |
| D14 | 正确 | 3 轮后仍错 | 开启组三轮都先筛选与影响区相交的水管，再仅裁剪到 A001，遗漏裁剪到影响区。W008 被量成 700 米，正确值约 220.710678 米；总长输出 1700 米，正确值约 1220.710678 米。工具调用均成功，三轮共 34 次调用。关闭组进行了第二次裁剪，13 次调用即得到正确结果。 |
| D20 | 错误 | 3 轮后仍错 | 两组最终都遗漏把影响范围内的水管再次裁剪到 A001，并使用 `group.code` 而非契约要求的 `group.source_code`。关闭组 13 次、开启组 37 次工具调用。开启组早轮还在解释文字中给出示例 JSON，解析器提取到了示例而非最终对象，削弱了后续反馈。 |
| D24 | 正确 | 3 轮后仍错 | 两组工具均能返回正确计数 5/5/2。开启组把工具按 Unicode 升序返回的“中压、低压、高压”改排为“低压、中压、高压”，三轮未纠正。此题还存在下述排序约定传达不完整的限制。 |
| D42 | 错误 | 3 轮后仍错 | 关闭组生成长篇重复解释，没有输出 JSON。开启组首轮误用 `ST_Within` 排除边界水管；后两轮改为相交查询，却遗漏裁剪到影响区，将 A002 内整段 1000 米当成实际受影响的 50 米。 |

各题的完整计划、反馈、工具轨迹和结果位于 [逐题记录目录](records/)，文件名如 `with_replan_D14.json`。标准答案 SQL 直接对“影响区与施工区求交”的有效范围裁剪水管，核查未发现上述空间题的参考 SQL 与题意不符。

## 解释范围与限制

1. 本轮未观察到重规划纠错收益：开启组 4 道首轮错误题均用尽两次重规划，0 道挽回。两组首轮是独立模型采样；开启组首轮正确时会直接停止。因此 D14、D24 的组间差异不能解释为“把同一条正确答复重规划成了错误答复”，也不能据此认定重规划机制普遍降低正确率。
2. D24 的 Unicode 排序规则存在于题集 `semantics`，但当前 `format_requirement()` 没有将此字段完整注入模型提示；题干只写“名称升序”。应把它视为排序/输出契约错误，同时承认排序约定传达不完整。若仅在同一批记录中排除 D24，关闭组为 47/49（95.92%），开启组为 46/49（93.88%），仍未出现题内挽回；这只是敏感性检查，不是另一次实验。
3. D42 关闭组的 240.015 秒属于模型长回复耗时，不能当作服务断线剔除：其 18 次 LLM 调用失败计数为 0，14 次工具调用均成功，任务和子任务异常字段为空，最终回复约 15092 字符却没有 JSON。未保存 `finish_reason`，无法进一步断言是否触及模型输出长度上限。这一长尾拉高了关闭组平均耗时，应同时看中位数和 P95。
4. 每道题、每种模式均从空能力状态、空共享经验和空智能体记忆开始，路由种子相同；题内重规划保留失败反馈和经验。这衡量的是隔离题目的重规划效果，未衡量跨 50 道题累积学习的收益。固定路由种子也不能保证模型输出完全确定。
5. 结果为一次 50 题配对的描述性比较，没有重复多个模型采样种子；模型调用量和 token 为本次正式任务的全轮次统计，未把运行前探测和单题冒烟测试计入。
